# Fonte Viva – sito e-commerce di Mathias Perego (1 Logistica)

Sito dimostrativo di un negozio online di borracce smart **Sorso**. Nessun pagamento reale.

## Struttura
| File | Cosa contiene |
|---|---|
| `index.html`, `negozio.html`, `prodotto.html`, `carrello.html`, `checkout.html`, `conferma.html`, `spedizioni.html`, `contatti.html`, `404.html` | le pagine (struttura) |
| `stile.css` | la grafica |
| `script.js` | le azioni: carrello, filtri, checkout (usa `localStorage`) |
| `prodotti.js` | il catalogo prodotti: per aggiungerne uno basta copiare un blocco |
| `img/` | foto prodotto 1600×1600 (viste studio, sera e dettaglio) |

## Pubblicare su GitHub Pages
1. Crea un repository e carica **tutti** i file di questa cartella (compresa `img/` e il file `.nojekyll`).
2. Settings → Pages → *Deploy from a branch* → `main` / `(root)`.
3. Dopo un minuto il sito è su `https://TUO-NOME.github.io/NOME-REPO/`.

## Provarlo in locale
Doppio clic su `apri_sito.bat` (Windows) oppure apri `index.html` nel browser.

Codice sconto di prova: **CIAO10** (−10%).
